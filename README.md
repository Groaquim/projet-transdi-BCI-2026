# projet-transdi-BCI-2026
Ce site web présente le projet transdisciplinaire mené sur l'année 2026 par BEN MECHICHI Youssef, CANARD Mathis, CAO Cheng et DAUBAGNA--LEFEBVRE Joaquim. L'objectif de ce projet était d'évaluer un effet de fatigue et son impact lors de l'utilisation prolongée d'un système BCI dans une tâche d'écriture.
